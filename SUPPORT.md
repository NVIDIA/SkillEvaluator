# Support

Support level: **Experimental**.

Skill Evaluator is community-supported software. Support is provided on a
best-effort basis by the maintainers through
[GitHub Issues](https://github.com/NVIDIA/SkillEvaluator/issues); there is no
SLA and no NVIDIA enterprise support entitlement for this project.

- Reproducible bugs and feature requests: open a GitHub Issue using the
  provided templates.
- Usage questions: open a GitHub Issue; check
  [docs/](docs/) and the [README](README.md) first.
- Security issues: follow [SECURITY.md](SECURITY.md) instead of opening a
  public issue.
