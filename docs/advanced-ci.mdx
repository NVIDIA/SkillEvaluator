Standard repository onboarding runs quality and security checks without
a model key. All-tier CI is a separate **explicit opt-in** for GitHub and GitLab.
Install SkillEvaluator 1.2.0 or later to use the released setup. A committed
caller uses its existing pins until you update them. [Installation](/skills/skillevaluator/installation#install)

## Before you opt in

- **Tier 2:** configure a model provider, embeddings provider and their keys.
  Anthropic chat defaults to OpenAI embeddings and needs that key too. See
  [providers and credentials](/skills/skillevaluator/configuration) and
  [deduplication](/skills/skillevaluator/tier2-deduplication).

  For NVIDIA Build embeddings, set `embedding-model` on GitHub or
  `SKILL_EVAL_EMBEDDING_MODEL` on GitLab to `nvidia/nemotron-3.5-embed-1b`.
  This setting applies to both native and prebuilt Tier 2 runtimes. NVIDIA Build
  retired the hosted endpoint for `nvidia/nemotron-3-embed-1b`.
  [NVIDIA API reference](https://build.nvidia.com/nvidia/nemotron-3_5-embed-1b/apireference)
- **Tier 3:** configure a supported provider, agent and Docker or native local
  runtime, and commit native datasets under each skill's `evals/` directory.
  CI consumes those cases with paired positive and negative coverage; it does
  not generate them. See [datasets](/skills/skillevaluator/eval-datasets) and
  [agents and runtimes](/skills/skillevaluator/agents-and-sandboxes).
- **Platform setup:** provide compatible runners and trusted execution/feedback
  environments. Merge the trusted feedback entrypoint onto the default branch
  before expecting automatic PR or MR comments. GitLab additionally needs its
  protected-branch, environment, token and existing-pipeline setup.

## Setup and retained evidence

Follow the [complete setup and maintainer reference](https://github.com/NVIDIA/SkillEvaluator/blob/main/ci/templates/all-tiers/README.md)
for GitHub and GitLab commands, migration, admission, feedback, runner and
timeout requirements, descriptor maintenance and retained report contracts.
It also documents SkillEvaluator's own callers and alternative feedback filename.

Only quality and security checks gate this CI integration. Tier 2 and Tier 3
remain advisory even when failed or incomplete; deprecated Tier 3 required settings are ignored.
When a tier is selected, missing credentials, runtime or datasets remain visible
as incomplete or needs-action evidence. A passing scan does not mean all
evaluation stages passed.
With `scan-mode: auto`, a pull request that changes no skill, such as a setup,
pin, model or secret change, skips the provider-backed jobs. Their prerequisites
are first checked by the push to the default branch after it merges, a manual
run there, or the next skill change. To check them before merging, set
`scan-mode: all` (GitLab: `SKILL_EVAL_SCAN_MODE: all`) on that pull request and
restore `auto` before merging. `skillevaluator ci demo --tiers 1,2,3` works only after the setup
has merged.

Reports retain native evidence and an aggregate artifact for 14 days. Feedback
links to the authenticated artifact for that run; download and extract it,
then open `index.html`. Hosted HTML is a separate option. Local setup, status
and demo commands do not prove provider-backed evaluation succeeded.

## Prebuilt Tier 2 image

The 1.2.0 pins use the locked on-runner Tier 2 install. Newer workflow revisions
that support the prebuilt runtime can run Tier 2 on a Linux x86-64 Docker runner
with the same provider credentials and advisory policy.

- **GitHub:** update `jobs.skills.uses` to a supporting workflow revision and
  set `tier2-image` under `jobs.skills.with`. If you use trusted feedback,
  update its tools and producer workflow pins and refresh the approved caller
  blob.
- **GitLab:** set `SKILL_EVAL_TIER2_IMAGE` in the root CI variables so the job
  rules can select the image. Keep provider credentials scoped to the execution
  environment and update the pinned remote include to a supporting revision.

Set the image to `ghcr.io/nvidia/skillevaluator-tier2@sha256:<digest>` and the
tools ref to the corresponding source commit. Use the digest and source commit
reported by [Release Tier 2 image](https://github.com/NVIDIA/SkillEvaluator/actions/workflows/release-tier2-image.yml)
after the public image verification step succeeds. Leave the image input empty
to install from the locked tools revision during the job.

The GitHub image uses its bundled system CA store and the runner's HTTP proxy
settings. Use the native runtime if your provider needs a custom host CA bundle.
