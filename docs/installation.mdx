One installation for all three tiers.

<div id="install">
<div id="install-the-cli">

```bash title="Install SkillEvaluator"
uv tool install --python 3.13 "skillevaluator[all] @ git+https://github.com/NVIDIA/SkillEvaluator.git"
```

<div id="requirements">

Requires **uv and Git**. uv sets up Python 3.13 automatically. This installs
the current GitHub source with all evaluation dependencies.

</div>
</div>
</div>

<div id="get-uv">

<Accordion title="Need uv?">
  Run the command for your operating system, then open a new terminal.

  <Tabs>
    <Tab title="macOS / Linux">

  ```bash title="Install uv"
  curl -LsSf https://astral.sh/uv/install.sh | sh
  ```

    </Tab>
    <Tab title="Windows">

  ```powershell title="Install uv in PowerShell"
  powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  ```

    </Tab>
  </Tabs>

  See [uv's installation guide](https://docs.astral.sh/uv/getting-started/installation/)
  for other package managers. Install Git too if `git --version` is unavailable.
</Accordion>

</div>

## Verify your install

```bash title="Check the CLI"
skillevaluator --version
```

You should see a version number. If the command is not found, run
`uv tool update-shell` and open a new terminal.
