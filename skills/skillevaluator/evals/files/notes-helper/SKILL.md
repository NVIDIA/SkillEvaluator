# Notes Helper

Turn raw meeting notes into a short summary with decisions and action items.

## Workflow

1. Read the notes the user provides.
2. List the decisions that were made.
3. List action items with an owner and due date when given.

## Example

Input: "Ana will ship the beta Friday. We chose Postgres."
Output: Decisions: use Postgres. Actions: Ana - ship beta - Friday.
