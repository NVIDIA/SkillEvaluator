A SMALL, LOCAL WORKFLOW
Start with a skill and one task.
  1. Add your skill. Add a Markdown document or skill package from your computer, paste instructions, or try the working sample. We keep a separate local copy; your original files stay unchanged.
  2. Review test cases. Draft a template without a key, or connect a model for an assisted draft. Edit and save cases before evaluating.
  3. Run and inspect. Check the dataset, run static checks, or evaluate with an agent. Expand each case for the actual response and checks.
  4. Improve (optional). Review the evidence, edit a separate copy, and evaluate it. A draft edit is not a measured improvement.
One background task at a time. Drafting, checks, dataset validation, and evaluations share one background slot in this app. You can keep adding skills and editing while it works. An evaluation can include many cases, with concurrent trials set in Advanced options.
This interface uses the installed SkillEvaluator. It does not train model weights. Automatic optimization and trajectory-based dataset generation are integration points for future backend capabilities.
